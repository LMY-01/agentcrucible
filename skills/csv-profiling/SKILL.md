# CSV 数据画像

## 步骤

1. 先 `list_dir` 确认文件名，不要假设扩展名。
2. 用 `run_python` 读文件，**不要**直接把整个 CSV 塞进上下文——超过 50 行就会浪费大量 token 并且看不清结构。

```python
import csv
with open("文件.csv", newline="", encoding="utf-8") as fh:
    rows = list(csv.DictReader(fh))
print(len(rows), "行")
print(list(rows[0].keys()) if rows else "空文件")
```

3. 逐列判定类型，顺序固定：整数 → 浮点 → 日期（YYYY-MM-DD）→ 文本。
4. 统计每列的缺失率，缺失值包括：空字符串、`NA`、`N/A`、`null`、`-`。
5. 数值列额外算：最小值、最大值、均值、以及超过均值 ± 3 倍标准差的离群点个数。

## 输出格式（必须是这张表，不要改列名）

| 列名 | 类型 | 缺失率 | 唯一值 | 说明 |
|---|---|---|---|---|

表格后面跟三段：

- **结论**：一句话说明这份数据能不能直接用于分析。
- **风险**：列出缺失率 > 20% 的列，以及离群点最多的列。
- **建议**：给出具体的清洗动作，每条都要能执行。

## 注意

- 样本少于 10 行时不要下"数据质量好/差"的结论，只描述事实。
- 数字保留两位小数，不要写"约"、"大概"这类模糊词。
